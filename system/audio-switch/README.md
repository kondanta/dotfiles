# audio-switch

Switches the active port on the onboard analog audio sink between headphones and line-out (speakers).

Bound to `mod+shift+i` (IEMs) and `mod+shift+p` (speakers) in Hyprland.

## Files

| Source (this repo) | System path |
|---|---|
| `audio-switch` | `/usr/local/bin/audio-switch` |

## Deploying after changes

```fish
sudo cp audio-switch /usr/local/bin/audio-switch
sudo chmod +x /usr/local/bin/audio-switch
```
